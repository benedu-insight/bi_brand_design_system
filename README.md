# Benedu Brand Design Systems

Benedu Insight와 benedu atelier, 두 브랜드의 디자인 시스템을 모은 정적 사이트입니다.

| 경로 | 내용 |
|---|---|
| `index.html` | 두 브랜드를 소개하는 영어 시작 페이지 (히어로 한 화면, 모션 그래픽) |
| `benedu-insight/` | 부모 브랜드 — 반도체 플라즈마·RF 전문 교육. 디자인 시스템 페이지, `DESIGN.md`, 로고 SVG 19개 |
| `benedu-atelier/` | 교육 브랜드 — 기업 실무 AI 교육. 디자인 시스템 페이지, `DESIGN.md`, 로고 SVG 9개 |

## 쓰는 법

AI에게 문서·슬라이드·웹 페이지를 만들게 할 때 해당 브랜드의 `DESIGN.md`를 함께 첨부하고
"이 디자인 시스템을 따라 만들어 줘"라고 요청합니다. 로고는 `logo/` 폴더의 SVG를 씁니다.

## 서체 안내

페이지는 설치된 서체(Google Sans, 한국기계연구원, 에이투지체)가 있으면 그것으로, 없으면
Gowun Batang · Pretendard 등 웹 서체로 대신 보입니다. 로고 SVG는 모두 아웃라인이라 서체가 필요 없습니다.

원본 관리 위치: 로컬 Brand Kit(`07_Brand_Kit`). 이 저장소는 게시용 사본입니다.
